# Statistiques administrateur

La V9 ajoute un tableau de bord statistique réservé au rôle Administrateur.

Périodes disponibles : 7, 30, 90 et 180 jours.

Indicateurs : tickets créés/résolus, tickets ouverts, temps moyen de résolution, tickets critiques, non attribués, validations Manager, utilisateurs actifs.

Répartitions : statut, importance, type et groupe du demandeur.

Le graphique d'évolution est rendu localement en JavaScript sans bibliothèque externe.
