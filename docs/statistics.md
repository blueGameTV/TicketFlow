# Statistiques TicketFlow

La page Statistiques est réservée aux Administrateurs.

## Périodes

Les périodes proposées permettent d'analyser l'activité récente, notamment sur 7, 30, 90 ou 180 jours selon l'interface disponible.

## Indicateurs

TicketFlow peut afficher notamment :

- tickets créés ;
- tickets résolus ;
- tickets ouverts ;
- temps moyen de résolution ;
- tickets non attribués ;
- tickets critiques ouverts ;
- validations Manager en attente ;
- dépassements SLA ;
- utilisateurs actifs.

## Répartitions

Les statistiques peuvent être regroupées par :

- statut ;
- importance ;
- type ;
- groupe du demandeur.

## Graphique d'évolution

Le graphique d'évolution présente les tickets créés et résolus sur la période sélectionnée.

Il est rendu directement par l'interface TicketFlow sans dépendre d'un service graphique externe.
