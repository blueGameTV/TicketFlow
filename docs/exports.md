# Extractions Excel

Les extractions sont réservées à l'Administrateur.

## Période

Chaque extraction couvre au maximum **6 mois**.

## Extraction utilisateurs

Elle permet de suivre notamment :

- comptes ;
- rôles ;
- groupes ;
- Manager ;
- date d'arrivée ;
- état du compte ;
- dernière connexion.

## Extraction tickets

Les tickets peuvent être filtrés selon plusieurs critères :

- type ;
- statut ;
- importance ;
- groupe du demandeur ;
- Support IT assigné.

Le fichier contient les principales informations utiles au suivi et au reporting.

## Rapport opérations & disponibilité

Ce rapport regroupe les opérations de service introduites avec la v1.1.0 :

- alertes de service ;
- maintenances ;
- périodes ;
- états ;
- informations de suivi.

## Format

Les fichiers sont générés au format `.xlsx` compatible avec Microsoft Excel.

L'import massif d'utilisateurs est documenté séparément dans [user-import.md](user-import.md).
