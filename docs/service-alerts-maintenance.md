# Alertes de service et maintenance

## Alertes de service

Les Administrateurs et membres Support IT autorisés peuvent publier une alerte globale afin d'informer les utilisateurs d'un incident, d'une dégradation ou d'une intervention.

Une alerte contient notamment :

- application ou service ;
- niveau ;
- titre ;
- message ;
- début ;
- fin prévue ;
- état.

Le titre est limité à **80 caractères** et le message à **2000 caractères**.

Le bandeau principal affiche le titre. Un clic permet de consulter le détail complet.

## Historique

La page d'administration conserve l'historique des alertes.

L'Administrateur peut supprimer les alertes résolues de l'historique avec l'action prévue à cet effet.

## Maintenance immédiate

L'Administrateur peut activer le mode maintenance immédiatement avec :

- un message ;
- une date de fin estimée ;
- l'autorisation ou non du Support IT pendant l'intervention.

Les Administrateurs conservent toujours l'accès.

Les Collaborateurs et Managers sont redirigés vers la page de maintenance lorsque l'accès est bloqué.

## Fin automatique

Si une fin estimée est définie, TicketFlow désactive automatiquement le mode maintenance lorsque l'heure est atteinte.

## Maintenance planifiée

Une maintenance future peut être programmée avec :

- titre ;
- message ;
- début ;
- fin ;
- blocage optionnel de TicketFlow.

Un bandeau peut informer les utilisateurs avant le début de l'intervention.

## Rapport

Les alertes et maintenances peuvent être exportées depuis **Extractions Excel → Rapport opérations & disponibilité**.
